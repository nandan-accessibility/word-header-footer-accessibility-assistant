Word Header & Footer Accessibility Assistant

NVDA add-on by Nandan Kumar Singh

About

Word Header & Footer Accessibility Assistant is an NVDA add-on designed to improve access to Microsoft Word headers and footers for blind and visually impaired users.

It provides simple keyboard commands to read and edit the header and footer of the current Microsoft Word section.

Features

  • Read the current Header.
  • Read the current Footer.
  • Read both Header and Footer.
  • Edit the current Header.
  • Edit the current Footer.
  • Support for different first-page headers and footers where available.
  • Support for different odd and even page headers and footers where available.

Keyboard Shortcuts

Shortcut Action
NVDA+Shift+H Read the current Header.
NVDA+Shift+F Read the current Footer.
NVDA+Shift+W Read both Header and Footer.
NVDA+Ctrl+Shift+H Edit the current Header.
NVDA+Ctrl+Shift+F Edit the current Footer.

Usage

Open a Microsoft Word document and place the cursor inside the document. Use the appropriate keyboard shortcut to read or edit the Header or Footer.

When an Edit command is used, the add-on moves the Word selection into the corresponding Header or Footer area, allowing the content to be edited using normal Microsoft Word keyboard commands.

Compatibility

Minimum NVDA version: 2021.1

Last tested NVDA version: 2026.3

Designed for Microsoft Word desktop applications that provide the required Word automation interface.
